# DirTreeView

Быстрая, современная утилита для визуализации дискового пространства и очистки диска на macOS.

DirTreeView предоставляет наглядное интерактивное представление структуры занятого дискового пространства с помощью древовидных карт (squarified treemaps). Приложение помогает мгновенно находить тяжелые файлы и папки на встроенных накопителях, внешних дисках и в отдельных директориях, делая анализ и освобождение места простыми, быстрыми и безопасными.

---

## Почему выбирают DirTreeView?

- **Высокая скорость работы без зависаний**: Разработано на Rust со встроенным многопоточным сканированием. Анализирует миллионы файлов за считанные секунды, сохраняя интерфейс отзывчивым на стабильных 60 FPS.
- **Точный учет файловой системы APFS**: Измеряет реальное физическое пространство на диске, а не только номинальный размер файлов. Корректно учитывает разреженные файлы (sparse files) и исключает повторный подсчет жестких ссылок и APFS-клонов copy-on-write.
- **Легковесность и производительность**: Построено на нативном графическом движке с прямым GPU-рендерингом. Минимальное потребление оперативной памяти, отсутствие тяжелых веб-фреймворков и накладных расходов Electron.
- **Встроенная безопасность**: Защитные механизмы предотвращают случайное удаление ключевых системных каталогов macOS (`/`, `/System`, `/usr`, `/bin`, домашние директории). Прямая интеграция с Корзиной macOS для безопасного удаления с возможностью восстановления.

---

## Основные возможности

- **Интерактивная древовидная карта (Squarified Treemap)**: Пропорциональные прямоугольные блоки отображают объемы папок и файлов. Кликните для просмотра точного размера и процента; дважды кликните для перехода внутрь подпапки.
- **Списки «Топ-10 папок» и «Топ-20 файлов»**: Удобные панели для быстрого выявления самых объемных папок в текущей области и самых тяжелых файлов за всё сканирование.
- **Фильтрация и поиск в реальном времени**:
  - Быстрый текстовый поиск по именам файлов и каталогов.
  - Логарифмический ползунок порога размера для скрытия мелких несущественных элементов.
- **Поддержка внешних накопителей**: Быстрый выбор подключенных внешних дисков, флешек и смонтированных разделов из `/Volumes`.
- **Drag & Drop**: Перетащите любую папку из Finder прямо в окно приложения для мгновенного запуска сканирования.
- **Интеграция с Finder и Корзиной**: Правый клик по любому элементу позволяет открыть его в Finder, отправить в Корзину macOS или удалить навсегда с подтверждением через модальное окно.

## Установка и скачивание

### Готовые сборки (.dmg / .app)

**Компилировать исходный код не обязательно.** Готовые образы дисков `.dmg` и приложения `.app` публикуются для каждого релиза:

1. Скачайте последнюю версию из раздела [GitHub Releases](https://github.com/Samuconfaa/DirTreeView/releases).
2. Откройте файл `.dmg` и перетащите **DirTreeView** в папку «Программы» (`/Applications`).

> [!NOTE]
> Если при первом запуске macOS Gatekeeper заблокирует неподписанную сборку, нажмите по приложению правой кнопкой мыши → **Открыть**, либо снимите атрибут карантина в Терминале:
> ```bash
> xattr -cr /Applications/DirTreeView.app
> ```

### Сборка из исходного кода (Опционально)

Если вы хотите собрать проект самостоятельно:

#### Требования
- macOS 11.0 (Big Sur) или новее
- Apple Silicon (M1/M2/M3/M4) или Intel x86_64
- Инструменты разработки Rust (`cargo`) и Xcode Command Line Tools

```bash
# Прямой запуск
cargo run --release

# Сборка пакета .app
cargo install cargo-bundle
cargo bundle --release
```

## Разрешения macOS (Полный доступ к диску)

macOS защищает личные данные пользователя (такие как Почта, Сообщения, история Safari и медиатека Фото) с помощью системы TCC (Transparency, Consent, and Control).

Чтобы DirTreeView мог сканировать весь системный диск без ошибок доступа:

1. Откройте **Системные настройки** → **Конфиденциальность и безопасность** → **Полный доступ к диску**.
2. Нажмите **+** и выберите **DirTreeView** (или скомпилированный бинарный файл).
3. Перезапустите приложение.

*(Также можно нажать кнопку **Full Disk Access** в верхней панели приложения, чтобы сразу открыть нужный раздел настроек).*
